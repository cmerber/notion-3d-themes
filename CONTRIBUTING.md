# Contributing

This repository packages Orange and Island as a configurable NotionNext starter.
Open issues and pull requests against this repository, not the demo site's CMS.

Keep changes focused, retain MIT/third-party notices, and never commit credentials.
Run `corepack yarn check:starter`, tests, model checks, type checking and a production
build before submitting code. See [development](./docs/development.md).

For upstream engine changes, consult [NotionNext](https://github.com/notionnext-org/NotionNext).
